\section{Processing Steps}
The workflow has four stages. Each stage records a short status message and a validation result.

\begin{itemize}
\item Read the configuration file.
\item Normalize the values.
\item Validate the selected profile.
\end{itemize}

The normalized score is $s = q/t$.

\begin{equation}
R = \frac{accepted}{received + skipped}
\end{equation}
