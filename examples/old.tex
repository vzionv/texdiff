\section{Configuration Guide}\label{sec:guide}
This guide describes a small configuration workflow. Clear defaults make each change easy to review.

The first draft stores settings in one local file and validates the values before processing.

\section{Processing Steps}
The workflow has three stages. Each stage records a short status message.

\begin{itemize}
\item Read the configuration file.
\item Normalize the values.
\end{itemize}

The normalized score is $s = p/r$.

\begin{equation}
R = \frac{accepted}{received}
\end{equation}
